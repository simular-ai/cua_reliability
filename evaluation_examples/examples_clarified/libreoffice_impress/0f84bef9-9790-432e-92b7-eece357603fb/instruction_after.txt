Whenever I start LibreOffice Impress it uses both screens (the Presenter Screen with current/next slide on one, and the actual slide show on the other). I want only a single monitor showing the slide show, with no Presenter Screen, so the second monitor can be used for other tasks. Please disable the Presenter Screen (aka Presenter Console) in Impress so that the LibreOffice user config reflects this: in /home/user/.config/libreoffice/4/user/registrymodifications.xcu, under /org.openoffice.Office.Impress/Misc/Start, the EnablePresenterScreen setting should be set to false.
