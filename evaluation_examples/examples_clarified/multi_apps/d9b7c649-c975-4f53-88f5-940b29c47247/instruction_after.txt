Please use the Thunderbird profile that’s provided, go to the mail folder named “daily” (under Local Folders in that profile), take the five most recent messages by received date/time from that folder, then list those five in ascending order (earliest to latest among the five). Create an Excel workbook (xlsx, not ods) named report.xlsx on the Desktop at /home/user/Desktop/report.xlsx. Put the table on the first sheet, starting at A1, with a header row exactly in this order and spelling: sender_name, sender_address, subject, CC, number_of_attachments. For sender_name use the display name from the From header; for sender_address use only the email address (no angle brackets or name). For CC, include email addresses only, comma-separated if there are multiple, and leave it blank if none. For number_of_attachments, write the integer count of attachments for each message. Include exactly these five rows (no extra rows).
