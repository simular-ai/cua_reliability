On Ubuntu, use sar from the sysstat package to record overall CPU usage (the aggregated CPU report, not per‑CPU) once per second for 30 samples. Make sure the output includes the header with the fields CPU, %user, %nice, %system, %iowait, %steal, and %idle. Save the complete output—including the header and all samples—as a plain text file at /home/user/Desktop/System_Resources_Report.txt. The saved file should contain 31 timestamped lines in total (the header line with a time plus 30 one‑second samples).
